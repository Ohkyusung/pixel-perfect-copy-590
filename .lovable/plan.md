

## 분석 결과

**원인**: 결과 화면에서 손가락을 뗄 때 발생하는 타이머 경쟁 조건(race condition)

현재 로직:
1. 결과 표시 → 3초 자동 리셋 타이머 시작
2. 손가락 모두 떼면 → 3초 타이머 **삭제** → 1초 타이머로 교체
3. 여러 손가락을 하나씩 떼면 중간에 `touches.length > 0` 상태가 발생 → 1초 타이머도 **삭제**
4. **두 타이머 모두 사라져서 영원히 리셋 안 됨**

## 수정 계획

**`src/components/TouchArea.tsx`** 한 파일만 수정:

- 3초 자동 리셋 타이머는 **절대 삭제하지 않고** 항상 동작하도록 유지
- 손가락을 모두 뗐을 때는 3초 타이머를 유지한 채 **추가로** 1초 타이머를 설정하여 더 빨리 리셋
- `doReset`에서만 모든 타이머를 정리하도록 단순화
- 손가락 다시 올렸을 때 1초 빠른 리셋만 취소하고, 3초 안전망은 유지
