

## 계획: 좌측 상단 설정 + 우측 상단 리셋 버튼

### 변경 파일: `src/components/TouchArea.tsx`

**좌측 상단 - 당첨 인원 설정 드롭다운:**
- idle 상태일 때 좌측 상단에 현재 모드/인원을 보여주는 버튼 배치
- 클릭 시 모드 선택 (1명, 2명, 3명, 4명, 5명) 드롭다운 또는 토글 UI 표시
- `pick-one`이면 "1명", `pick-n`이면 "N명" 형태로 표시
- 터치 이벤트 전파 방지 (`e.stopPropagation()`)

**우측 상단 - 리셋 버튼:**
- idle이 아닌 모든 상태에서 우측 상단에 리셋(X 또는 RotateCcw) 아이콘 버튼 표시
- 클릭 시 `doReset()` 호출하여 즉시 초기 화면으로 복귀
- 터치 이벤트 전파 방지

**UI 스타일:**
- 반투명 배경 (`bg-muted/40 backdrop-blur-sm`) 원형 버튼
- `z-50`으로 터치 영역 위에 렌더링
- `pointer-events-auto`로 터치 가능하게 설정
